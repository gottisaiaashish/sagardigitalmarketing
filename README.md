# sagardigitalmarketing

> Premium Editorial Digital Marketing & Brand Growth Studio

## Overview
A high-prestige, luxury editorial agency website engineered for **Sagar Digital Marketing**. Built to empower ambitious small businesses, cafes, restaurants, fashion brands, and professional practices with unmistakable visual identity, commercial precision, and high-ROAS localized customer acquisition.

## Tech Stack & Architecture
- **Design System**: Luxury Dark Editorial Aesthetic (`#0A0A0A` onyx, luminous sunset coral `#E87348`, Newsreader & Cormorant Garamond serif typography).
- **Smooth Inertia Motion**: Lenis Smooth Momentum Scrolling (`lenis.min.js`).
- **React Bits Pro Components**:
  - **Bending Marquee** (`bending-marquee-tw`): Curved 3D perspective continuous ticker.
  - **Elastic Lettering** (`elastic-lettering-tw`): Interactive rubber-band physics with autonomous ripple waves.
  - **Momentum Ring / Vertical Reel** (`vertical-reel-tw`): 3D cylindrical case reel with dynamic velocity motion blur and magnetic snap.
  - **Scroll Portal** (`scroll-portal-tw`): Multi-frame zoom tunnel journey.
- **Frontend**: Clean Semantic HTML5, Tailwind CSS, Vanilla JS, and React 18 + Framer Motion.
- **Routing**: Clean URL structure (`/services`, `/our-work`, `/about-us`, `/contact`) with static directory mirrors and local Python server (`server.py`).

## Getting Started

### Local Static Server (Python)
```bash
python server.py
# Server runs on http://localhost:8080
```

### React / Vite Dev Server
```bash
npm install
npm run dev
```
